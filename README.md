# スカイライン・テクノロジーズ 企業サイト

スカイライン・テクノロジーズ株式会社の企業サイトです。業務システム・クラウド基盤・モバイルアプリの設計から運用までを担うソフトウェア開発会社として、事業内容や導入事例、採用情報を紹介します。

## サイト構成

`index.html` 1ファイルで構成された1ページのサイトです。ビルドやインストールは不要です。

| セクション | 内容 |
| --- | --- |
| お知らせ | 採用・プレス・事例の最新情報 |
| ヒーロー | キャッチコピー |
| 事業内容 | 業務システム開発、クラウド基盤構築・運用、モバイルアプリ開発、DX推進支援 |
| 導入事例 | 物流・医療・基幹システム移行の事例 |
| 開発の進め方 | ヒアリング → 設計・お見積り → 開発・検証 → リリース・運用 |
| 会社概要 | 会社情報と代表メッセージ |
| 採用 | 募集職種（バックエンド、SRE / インフラ、UI/UXデザイナー） |
| お問い合わせ | 問い合わせフォーム |

## ブラウザで開く手順

1. このリポジトリをクローンするか、フォルダを手元に用意します。
2. エクスプローラー（macOS は Finder）で `company-site` フォルダを開きます。
3. `index.html` をダブルクリックします。既定のブラウザでサイトが表示されます。
   - 別のブラウザで開く場合は、`index.html` を右クリックして「プログラムから開く」でブラウザを選ぶか、ブラウザのウィンドウへファイルをドラッグ＆ドロップします。

コマンドラインから開く場合は次のとおりです。

```sh
# Windows（PowerShell）
start index.html

# macOS
open index.html
```

> フォントは Google Fonts から読み込むため、インターネットに接続していない環境では代替フォントで表示されます。
